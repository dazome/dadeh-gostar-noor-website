# راهنمای راه‌اندازی — داده‌گستر نور

## پیش‌نیازها
- Node.js نسخه‌ی 22.12 یا بالاتر
- PostgreSQL

## ۱. دیتابیس
۱. یک دیتابیس (مثلاً `dadeh_gostar_noor`) و یک یوزر اختصاصی برای برنامه بسازید.
۲. فایل `server/schema.sql` را بدون هیچ تغییری روی همان دیتابیس اجرا کنید (در pgAdmin: Query Tool).

نکته‌ی مهم: اسم جدول‌ها و ستون‌ها را با کوتیشن نسازید و تغییر ندهید. کد به lowercase بودن آن‌ها وابسته است.

اگر schema را با یوزری غیر از یوزر برنامه اجرا کرده‌اید، دسترسی بدهید:

    GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA public TO نام_یوزر_برنامه;

## ۲. سرور (پوشه‌ی server)
۱. فایل `.env.example` را به `.env` کپی کنید و مقدارها را پر کنید:

| متغیر | توضیح |
|---|---|
| PORT | پورت سرور (پیش‌فرض 5000) |
| CLIENT_ORIGIN | آدرس سایت (فرانت)، مثلاً `https://example.com`. چند آدرس را با کاما جدا کنید |
| TRUST_PROXY | اگر سرور پشت nginx یا Cloudflare است `1` بگذارید، اگر مستقیم به اینترنت وصل است خالی بگذارید |
| DB_HOST / DB_PORT / DB_NAME / DB_USER / DB_PASSWORD | اطلاعات اتصال به PostgreSQL |
| JWT_SECRET | یک رشته‌ی تصادفی و طولانی (حداقل 64 کاراکتر) |
| ADMIN_EMAIL | ایمیل ورود به پنل مدیریت |
| ADMIN_INITIAL_PASSWORD | رمز اولیه‌ی ادمین، حداقل 12 کاراکتر |

۲. نصب و ساخت ادمین (فقط یک‌بار):

    npm install
    node createAdmin.js

۳. بعد از ساخت ادمین، خط `ADMIN_INITIAL_PASSWORD` را از `.env` پاک کنید.

۴. اجرا:

    npm start

پوشه‌ی `uploads` باید برای کاربری که سرور را اجرا می‌کند قابل نوشتن باشد و در بکاپ‌گیری لحاظ شود.

## ۳. فرانت‌اند (پوشه‌ی اصلی پروژه)
۱. فایل `.env.example` را به `.env` کپی کنید و آدرس سرور را بدهید (بدون اسلش آخر):

    VITE_API_URL=https://api.example.com

اگر فرانت و API روی یک دامنه هستند و nginx مسیرهای `/api` و `/uploads` را به سرور می‌فرستد، می‌توانید مقدار را خالی بگذارید.

۲. بیلد:

    npm install
    npm run build

خروجی در پوشه‌ی `dist` است و باید روی وب‌سرور قرار بگیرد. چون سایت SPA است، همه‌ی مسیرها باید به `index.html` برگردند (در nginx: `try_files $uri /index.html;`).

مقدار `VITE_API_URL` هنگام بیلد داخل کد قرار می‌گیرد؛ با تغییر آن باید دوباره بیلد بگیرید.

## ۴. بعد از راه‌اندازی
با ایمیل و رمز ادمین وارد پنل مدیریت شوید. اطلاعات شرکت، مشتریان، مجوزها و مقالات وبلاگ از همان‌جا وارد می‌شود.
